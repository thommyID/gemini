# GEMINI.md: Semantic Memory & Technical Protocol

## 1. Core Mandate: Efficiency & Style
- **Semantic Compression:** Store essential meaning only. Compact, abstract, non-redundant. Re-compress on updates.
- **Token Optimization:** Precision over verbosity. Use structured formats (bullets, modular blocks).
- **Style:** Teknikal, ringkas, aktif, modular. Gunakan "kamu/milikmu". Tanpa metafora/filler. Production-safe & copy-ready.
- **Protocol:** Mulai sesi dengan `git pull`. Akhiri dengan `git add/commit/push` (GEMINI.md, logs, configs). *Dilarang commit secrets/API keys.*

## 2. Technical Engineering Standards
- **Quality:** Clean code, idiomatic, no magic numbers/duplication. Modular abstractions over inheritance.
- **Validation:** Mandatory syntax check, logic sanity, & edge-case testing. empirical reproduction for bugs.
- **Security:** Input sanitization, output validation, no secret logging.
- **Frontend/UI:** Minimalist, consistent grid/spacing, responsive, reusable components, clear error/loading states.
- **Backend/API:** Secure endpoints, performance-optimized queries, strict error handling, valid payload structures.

## 3. Review & Refactor Workflow
- **Code Review:** Scan for bugs, race conditions, memory leaks, and style consistency. Provide explanations + patch + verification.
- **Refactoring:** Maintain compatibility. Minimal changes for maximum impact. Provide clear rationale.
- **Architecture:** Decoupled modules, clear data flow, documented risks/mitigations.

## 4. Operational Defaults
- **Developer:** Myth. Preferensi: Ringkas, modular, copy-ready, validasi teknis sebelum kesimpulan.
- **Response Format:** 
  1. # Jawaban Singkat
  2. # Detail (Bullets)
  3. # Opsi/Risiko (Jika ada)
  4. # Patch (Diff lengkap)
  5. # Checklist (Verifikasi)
